# 자동 업데이트와 새 버전 배포

## 사용하시는 분

1. [최신 버전 다운로드](https://github.com/6Zman8/archive-analyzer/releases/latest)에서 `ArchiveAnalyzer.exe`를 받습니다.
2. 문서 또는 바탕 화면 아래의 전용 폴더에 두고 더블클릭합니다. Python이나 GitHub 로그인은 필요하지 않습니다.
3. 프로그램이 시작되면 새 버전을 확인하고, 계속 켜 두면 6시간마다 다시 확인합니다.
4. 새 버전이 있으면 자동으로 내려받습니다. 검사 화면 아래쪽과 `업데이트` 메뉴에서 다운로드 비율과 준비 상태를 확인할 수 있습니다.
5. `준비 완료`가 보이면 작업을 마친 뒤 프로그램을 종료하세요. 종료 후 자동으로 교체되고 다음 실행부터 새 버전입니다.

`업데이트 → 업데이트 확인`으로 바로 확인할 수 있습니다.
자동 확인·다운로드·적용이 필요 없으면 `업데이트 → 자동 확인·다운로드·종료 시 적용` 체크를 끄세요.
수동 확인은 이 설정과 관계없이 사용할 수 있으며, 수동으로 준비한 업데이트도 종료 후 적용됩니다.

업데이트는 EXE 파일만 바꿉니다. 검사 DB, 검토 기록, 원본 압축파일과 화면 설정은 그대로 사용합니다.
진행 중인 검사를 강제로 종료하지 않습니다. 같은 실행파일을 여러 번 열었거나 폴더 쓰기 권한이 없으면
기존 버전을 유지하고 다음 실행에 실패 이유를 표시합니다. 필요하면 모든 검사기 창을 닫고 쓰기 가능한
전용 폴더에서 다시 실행하세요.

처음 배포되었던 자동 업데이트 기능이 없는 구버전은 **이번 실행파일로 한 번 직접 교체**해야 합니다.
그 뒤부터 자동 업데이트됩니다. 기존 파일명을 `압축파일 검사기.exe`로 유지해도 됩니다.

실행파일은 전체 파일을 받는 방식입니다. 현재 약 150 MB이며 바뀐 부분만 받는 차등 패치는 사용하지 않습니다.
인터넷이 안 되거나 다운로드 검증에 실패하면 프로그램을 계속 사용할 수 있습니다.
다운로드 파일의 SHA-256과 크기를 GitHub 정보와 대조하고, 정식 버전만 적용하며 다운그레이드는 하지 않습니다.
기동 검사 실패 시 이전 EXE로 복구합니다. Windows 전원이 갑자기 꺼지는 등의 상황에는 업데이트 기록과
이전 EXE를 `%LOCALAPPDATA%\ArchiveAnalyzer\updates` 안에서 확인할 수 있습니다.

## 배포하시는 분

프로그램 변경사항을 저장소의 `main`에 올린 다음 브라우저에서 진행합니다.

1. [Windows 새 버전 배포](https://github.com/6Zman8/archive-analyzer/actions/workflows/release.yml)를 엽니다.
2. **Run workflow**를 누릅니다. 브랜치는 `main`으로 둡니다.
3. 현재보다 큰 버전 번호(예: `1.1.1`)와 변경 내용을 입력하고 실행합니다.
4. 자동 검사가 끝나면 소스의 버전 번호와 태그가 기록되고, EXE와 SHA256SUMS가 Release에 공개됩니다.
5. 사용자의 프로그램은 다음 실행 또는 6시간 내 정기 확인 때 새 버전을 받습니다.

검사나 빌드가 실패하면 새 파일은 공개되지 않습니다. 동일한 버전을 다시 덮어쓰지 말고 다음 버전으로 배포하세요.
단순한 소스 업로드만으로 EXE가 바뀌지는 않습니다. 위 배포 작업 또는 아래 태그 배포가 완료되어야 합니다.

개발자는 `src/archive_analyzer/version.py`의 버전을 올려 커밋한 후 해당 `vX.Y.Z` 태그를 push해도 됩니다.
태그 번호와 소스 버전이 일치하지 않으면 자동으로 중단합니다.
직접 릴리스를 만들 때도 `vX.Y.Z` 정식 태그에 `ArchiveAnalyzer.exe` 이름으로 올리고 Latest로 지정해야 합니다.
초안·사전 릴리스, 검증 정보 없는 파일은 자동 적용하지 않습니다.

배포에는 GitHub 계정의 저장소 쓰기 권한이 필요합니다. 사용자의 프로그램 안에는 GitHub 토큰을 넣지 않습니다.
GitHub 로그인 정보, 개인 DB, 로컬 실행 기록, 개인 파일 경로는 저장소에 올리지 않습니다.

공식 동작 근거: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases),
[Release asset digest](https://docs.github.com/en/rest/releases/assets),
[수동 워크플로 실행](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow).
