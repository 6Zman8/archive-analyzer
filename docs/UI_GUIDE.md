# 화면과 기능 위치

검토 화면에서 그룹을 선택한 뒤 오른쪽 파일 목록과 이미지를 비교하세요.
자주 쓰는 **이미지 정밀분석 · 추천 적용 · 보존 · 제거 후보**는 바로 누를 수 있습니다.
나머지 기능은 창 위의 메뉴와 목록 옆의 설정 메뉴에 모았습니다.

| 하려는 작업 | 위치 |
| --- | --- |
| 추천값·추정값 적용, 검토결과 일괄작업, 미검토 보존 | **그룹 작업** |
| 선택 그룹 격리 되돌리기, 검토 초기화, 휴지통 이동 | **그룹 작업** |
| 이미지 정밀분석, 페이지 포함 관계, 판본 차이 분석 | **분석** |
| 추천 기준 설정 | **분석 → 추천 기준 설정** |
| 탐색기·반디뷰로 열기, 격리·되돌리기·휴지통 이동 | 파일 목록 아래 **선택 파일** 또는 상단 같은 이름의 메뉴 |
| 격리 폴더 선택·현재 위치 확인 | **파일** |
| 후보 CSV 내보내기 | **파일 → 후보 CSV 내보내기** |
| 그룹 필터·필터 해제·전체선택·표시 열 | 왼쪽 **목록 설정** |
| 파일 요약/상세 열·표시 열·필터 | 파일 목록 오른쪽 **표 설정** |
| 비교 관계의 표시 열·필터 | 왼쪽 아래 **관계 설정** |
| 차이 후보 페이지·좌우 교환·가로/세로 배치 | 이미지 위 **비교 도구** |
| 미리보기 확대·복귀 | 이미지 위 **확대 / 복귀** |
| 이전·다음 그룹 | 왼쪽 목록 아래 **이전 · 다음** |
| 이전·다음 페이지 | 이미지 위 **이전 쪽 · 다음 쪽**, 또는 이미지 위 마우스 휠 |
| 자동 업데이트 설정·진행 상태·수동 확인 | **업데이트** |
| 위치가 기억나지 않는 기능 | **도움말 → 기능 위치 안내** |

**보기** 메뉴에서도 목록 설정과 비교 도구에 접근할 수 있습니다.
왼쪽 탭은 후보 그룹, 검토된 그룹, 격리된 그룹, 휴지통·제거 이력, 문제 파일을 뜻합니다.
Ctrl/Shift 선택, 드래그 선택, 파일 우클릭의 Windows 메뉴, 열 머리글 정렬·필터는 그대로 사용할 수 있습니다.

추천·추정값 적용, 검토결과 일괄작업, 미검토 보존은 선택한 그룹이 없으면 현재 표시된 그룹을 대상으로 합니다.
실제 적용 전 미리보기/확인 단계가 표시됩니다. 그룹 복원·초기화·휴지통 이동과 분석에는 그룹 선택이 필요합니다.
분석 중에는 겹치는 작업을 실행할 수 없으며 **작업 중단**으로 중단할 수 있습니다.

## 참고한 화면 설계

- [Microsoft Command Bar](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/command-bar): 자주 쓰는 명령과 보조 명령을 구분하고 관련 작업을 메뉴로 묶는 기준.
- [WinMerge 비교 화면](https://winmerge.org/screenshots/?lang=en): 목록과 나란한 비교 영역을 중심으로 배치한 데스크톱 비교 도구.
- [Nielsen Norman Group의 Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/): 초기 화면의 선택지를 줄이고 고급 기능을 찾을 수 있는 위치에 두는 기준.

기능 삭제 없이 명령의 위치와 배치를 정리했습니다. 창 크기 1000×700, 1280×860, 1440×960에서
메뉴 접근, 버튼 잘림, 이미지 공간을 검사하고 원래 선택 범위와 작업 중 비활성화를 함께 검사합니다.
